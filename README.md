# 📚 BCA — Biblioteca Colaborativa Acadêmica

**Conhecimento que compartilhamos.**

A **Biblioteca Colaborativa Acadêmica (BCA)** é um projeto dedicado à organização, à descoberta e ao compartilhamento responsável de materiais acadêmicos. Seu objetivo é facilitar o acesso a conteúdos de estudo, reunindo materiais por disciplinas e períodos para tornar a rotina acadêmica mais organizada e acessível.

## 🎯 Objetivos

- 📖 Organizar materiais acadêmicos em um único lugar.
- 🔎 Facilitar a busca por conteúdos relacionados às disciplinas.
- 🗂️ Estruturar os materiais por períodos e áreas de estudo.
- 🤝 Incentivar a colaboração e o compartilhamento responsável do conhecimento.
- 🎓 Contribuir para uma experiência de aprendizagem mais organizada e acessível.

## ✨ Funcionalidades

- **Catálogo acadêmico:** organização dos conteúdos disponíveis.
- **Navegação por períodos:** acesso aos materiais conforme a estrutura curricular.
- **Páginas por disciplina:** espaço dedicado aos conteúdos de cada componente curricular.
- **Busca integrada:** ferramenta para localizar informações no site.
- **Interface responsiva:** navegação adaptada a computadores e dispositivos móveis.
- **Design minimalista:** identidade visual inspirada em uma proposta acadêmica, com tons de azul-marinho e dourado suave.

## 🚀 Executando localmente

Para executar a BCA no seu computador, você precisará ter o [Python](https://www.python.org/) e o Git instalados.

### 1. Clone o repositório

```bash
git clone https://github.com/MarcosViniDLL/bca.git
```

### 2. Entre na pasta do projeto

```bash
cd bca
```

### 3. Instale o MkDocs Material

```bash
python -m pip install mkdocs-material
```

### 4. Inicie o servidor local

```bash
python -m mkdocs serve
```

O site estará disponível em `http://localhost:8000/`.

## 🏗️ Gerando a versão final

Para verificar se o site pode ser compilado corretamente, execute:

```bash
python -m mkdocs build
```

Os arquivos gerados serão disponibilizados no diretório `site/`.

## 🌐 Publicação

O projeto utiliza o GitHub Pages para disponibilizar o site publicamente.

Para publicar uma nova versão, execute:

```bash
python -m mkdocs gh-deploy
```

Antes da publicação, recomenda-se verificar as alterações no servidor local e confirmar se a compilação ocorre sem erros.

## 🤝 Contribuições

Contribuições, sugestões e melhorias são bem-vindas.

Se você encontrar algum problema ou tiver uma ideia para aprimorar a BCA, poderá abrir uma *issue* no repositório. Alterações de código e documentação também podem ser propostas por meio de *pull requests*.

Toda contribuição deve respeitar os direitos autorais e as condições de distribuição dos materiais compartilhados.

## ⚖️ Uso responsável dos materiais

A BCA tem como princípio o compartilhamento responsável do conhecimento. Os materiais disponibilizados devem respeitar os direitos de seus autores e as licenças aplicáveis.

O compartilhamento de um conteúdo deve ocorrer somente quando houver autorização ou fundamento legal para sua distribuição.
